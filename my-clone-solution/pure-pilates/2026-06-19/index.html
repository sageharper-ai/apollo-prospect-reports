Deployment notes — WordPress

  1. In the WordPress admin, navigate to the SEO plugin settings (Yoast, Rank Math, or equivalent active on the site). Look for a Schema / Structured Data section or a "Custom JSON-LD" injection field scoped to the homepage.
  2. Add three separate JSON-LD blocks — paste each {...} payload above as its own block. Scope each to the homepage only, not site-wide.
  3. Save. Verify on the live homepage by viewing page source — three <script type="application/ld+json"> blocks should appear in <head>.
  4. Test each payload at Google's Rich Results Test ↗. LocalBusiness and Service should validate; FAQPage validates once entries are confirmed and a visible FAQ section is on the page.
  5. Submit the homepage URL in Google Search Console for re-indexing once schema is live.

If the WordPress SEO plugin doesn't support custom JSON-LD injection, the same three payloads can be added via the theme's functions.php using a wp_head action hook, scoped to the front page with is_front_page(). Apollo can provide the PHP wrapper on request.
